# Myilvendhan & Nishanthi Wedding

Create an elegant, premium traditional South Indian wedding reception invitation website for:

Myilvendhan & Nishanthi

Overall Design

Theme: Elegant traditional South Indian

Style: Premium, romantic, graceful and minimal — not overly flashy.

Use a sophisticated traditional palette such as ivory/cream, muted gold, deep green and subtle maroon accents.

Add delicate traditional Indian ornamental patterns, floral motifs, jasmine/temple-inspired borders and subtle gold detailing.

Use elegant serif typography for English headings and a refined complementary font for supporting text.

Smooth page-to-page transitions, gentle fade/slide animations and subtle parallax effects.

The website should feel like a luxury digital wedding invitation, optimized primarily for mobile phones.

Use soft instrumental/traditional Indian wedding-style background music with a clear music on/off button.

Do not include any other wedding events. This website is exclusively for the Wedding Reception.

PAGE 1 — WELCOME

Use the couple's uploaded photograph as the full-screen background/hero image.

Apply a subtle dark/soft translucent overlay so the text remains readable while keeping the photograph clearly visible.

Display:

With love and happiness,
we invite you to celebrate

Myilvendhan & Nishanthi

Wedding Reception

Add a short elegant welcoming message:

"Two hearts, one beautiful journey,
and a celebration surrounded by the people we love."

Include a subtle “Scroll to Begin” animation at the bottom.

Use delicate floral/ornamental framing around the text without covering the couple's faces.

PAGE 2 — SAVE THE DATE

Create an interactive “SAVE THE DATE” section.

Heading:

SAVE THE DATE

Initially hide the date underneath an elegant textured/ornamental scratch-off layer.

Create a realistic but elegant scratch-to-reveal interaction:

User can swipe/touch the screen to scratch away the layer.

Reveal the date underneath.

Add a subtle sparkle/glow effect when the date is fully revealed.

Do not make the interaction difficult on mobile.

Revealed date:

15 SEPTEMBER 2026

Below it:

Wedding Reception

Then display a beautiful live countdown timer:

DAYS : HOURS : MINUTES : SECONDS

The countdown should automatically count down to 15 September 2026.

Use India Standard Time (IST).

After the countdown reaches zero, replace it with:

The Day Has Arrived ✨

PAGE 3 — VENUE & LOCATION

Create a beautiful traditional venue section.

Heading:

THE CELEBRATION

Display:

Wedding Reception

15 September 2026

Sarasu Mahal
Aval Poondurai, Erode

Add an elegant location/map section.

Include a prominent:

Find Us

button.

Add a QR code for the venue location using the Google Maps location link provided/uploaded by the user.

The QR code should:

Be large enough to scan easily from another phone.

Have a clean ivory/white background.

Include a small decorative traditional border.

Include the caption:

Scan to view the location

Also include a button:

Open in Google Maps

which opens the venue location in Google Maps.

Add subtle traditional floral/leaf decorations around the venue information.

FINAL END CARD

Finish with a clean, emotional end card.

Display:

Thank You

We look forward to celebrating this beautiful occasion with you.

Then:

**With love,

Myilvendhan & Nishanthi**

Add a small elegant floral/ornamental motif underneath.

Use a slow fade-out animation and maintain the same premium traditional visual language.

INTERACTION & UX

Design for mobile-first viewing.

Make every section fit naturally on a phone screen.

Use smooth vertical scrolling between sections.

Add subtle transitions between pages/sections.

Keep animations elegant and lightweight.

Ensure text has excellent readability.

Make the QR code and Google Maps button easy to access.

Ensure the countdown works correctly on both Android and iPhone.

The website should load quickly despite the background photograph.

Include a small floating music on/off control.

Add a subtle progress indicator or section navigation if it doesn't clutter the design.

Important

Use the uploaded couple photograph as the Page 1 background.

Use 15 September 2026 as the only event date.

The final result should feel like a high-end traditional Indian wedding invitation, combining classic South Indian elegance with modern interactive web design.
